# Blakely Honors Banner Studio

A lightweight in-browser studio for creating banners and social graphics for the **Carolyn F. Blakely Honors Program** (University of Arkansas at Pine Bluff).

## Features

- Four starter templates with UAPB-inspired green and gold palettes
- Editable headline, subheadline, and tag line
- Custom primary, accent, and text colors
- Common export sizes (social share, hero, square, Facebook cover)
- One-click **Download PNG**

## Run locally

No build step required. Serve the folder with any static file server, or open `index.html` directly in a browser.

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

Push to `main` and enable GitHub Pages on this repository (root `/`) to host the studio publicly.
